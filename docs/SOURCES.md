# Sources and previews

The six applications are maintained in their own repositories under [mattvildibill](https://github.com/mattvildibill). This portfolio contains descriptions, links and static captures; it does not bundle the applications.

| Project | Implementation to inspect |
| --- | --- |
| Painted Worlds | `painted-worlds`: original-art collection, world navigation, reconstructed surfaces and source/provenance records |
| Fabric Reality Lab | `fabric-reality-lab`: event simulator, topology, workload policies and recorded analysis |
| Gravity, Unscripted | `gravity-unscripted`: worker solver, tighter rerun, saved independent trajectories and regression checks |
| Denver Explorer | `denver-spire-explorer`: geographic navigation, source geometry, asset pipeline, tour and map edition |
| F1 Live Tracker | `F1-live-tracker`: provider queue, scoped requests, recorded race replay and synthetic demo |
| Fort Collins Worlds | `fort-collins-worlds`: geographic reconstruction, protected core and local scenario interpretation |

Preview images are actual application captures. They illustrate a specific view, not a performance benchmark. F1's preview is a synthetic demonstration, not authenticated live timing. The Gravity preview shows the actual orbit application rather than a generic orbit illustration. Denver's city view is distinct from its separate 2D overview. See the current project descriptions and alt text for each capture's subject.

The projects keep artwork, geographic datasets and third-party licenses/credits alongside their own sources. Development uses AI-assisted tools. No employment achievements, adoption metrics, or unaided-authorship claims are inferred from the screenshots or code.

`RECOVERY.md` preserves the historical revisions used during the earlier bundled deployment. Its old paths and integration details are a historical record, not the current delivery architecture. Current deployment information is in `DEPLOYMENT.md`.
